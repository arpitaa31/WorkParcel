# WorkParcel 0.2.0 Beta 3

The current 0.2.0 beta is Beta 3. See RELEASE-NOTES-0.2.0-beta.3.md for the complete release notes.

WorkParcel saves the apps, files, folders and web links connected to a task, lets you pack that setup away, and reopen it later. Web links are ordinary HTTP/HTTPS records opened through the Windows default browser. Capture and Pack Away operate on whole application windows; they do not inspect, restore, or close individual browser tabs.
